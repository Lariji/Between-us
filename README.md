# Between Us

A private, two-player question game for couples to play together while apart.

## Features

- Private rooms for two players
- Random relationship questions
- Independent answers and private ratings
- Shared score and round progression

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
